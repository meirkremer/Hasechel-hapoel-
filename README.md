# השכל הפועל

אתר תוכן עצמאי בעברית העוסק בידע, מדע, היסטוריה, תרבות, חברה ורעיונות. לצד הכתבות פועל מדור נפרד בשם **גילוי האינטרנט**, המוקדש לסקירות של אתרים, ספריות דיגיטליות, ארכיונים ופרויקטים מעניינים מרחבי העולם.

האתר סטטי ומפורסם באמצעות GitHub Pages. עמוד הבית נמצא ב-`index.html`, כתבות עומק בתיקיית `articles/`, וסקירות אתרים בתיקיית `internet/`.

כתובת האתר: https://meirkremer.github.io/Hasechel-hapoel-/
