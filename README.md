# השכל הפועל

אתר תוכן עצמאי בעברית, בנוי באמצעות Jekyll ומפורסם ב-GitHub Pages.

## לסוכני AI וכלי פיתוח

לפני כל עבודה במאגר, יש לקרוא את **[AGENTS.md](AGENTS.md)**. זהו מסמך ההנחיות המחייב שמסביר את הארכיטקטורה, מבנה התוכן, כללי הפרסום, גבולות הגזרה של סוכני תוכן ופיתוח, ונהלי הבדיקה והפריסה.

## מבנה התוכן

- `_articles/patents/` — פטנטים
- `_articles/syllabi/` — סילבוסים
- `_articles/open-source/` — קוד פתוח
- `_articles/internet-discovery/` — גילוי האינטרנט

כל כתבה נשמרת בקובץ Markdown יחיד בתיקיית הסקטור. Jekyll מייצר ממנה אוטומטית עמוד כתבה עצמאי, ובונה את כרטיסי המהדורה ואת עמודי הסקטורים.

## תצוגות

- עמוד הבית הוא מהדורה עדכנית אחת, המציגה גריד עם הכתבה האחרונה מכל סקטור.
- כל כרטיס מציג את שם הסקטור, תאריך, כותרת ותקציר, ומוביל לעמוד הכתבה.
- לכל סקטור עמוד אחד המציג את כל כתבותיו מהחדשה לישנה.
- אין ארכיון מהדורות; אין צורך ליצור ידנית עמוד HTML עבור כתבה.

ראו `CONTENT_GUIDE.md` להנחיות כתיבה. לפיתוח מקומי: `bundle install` ואז `bundle exec jekyll serve`.
