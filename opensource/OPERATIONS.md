# מדור פרויקטים בקוד פתוח — תפעול

המדור נמצא תחת `/opensource/` והכתבות מתפרסמות תחת `/opensource/articles/`.

## מחזור יומי

1. בשעה 06:00 UTC פונקציית Supabase `oss-daily-discovery` אוספת מועמדים ממקורות הגילוי הפעילים ושומרת אותם ב-Supabase.
2. בשעה 06:20 UTC פונקציית `oss-research-publish` בוחנת עד עשרה מועמדים, מאמתת רישיון מתוך רשימת רישיונות מאושרים, קוראת README, קובצי manifest, metadata ועד חמישה commits אחרונים.
3. מודל AI מדרג את המועמדים לפי מחוון של 100 נקודות וכותב כתבות בעברית.
4. נבחרים עד שלושה פרויקטים, תוך איזון בין פרויקטים מבוססים לפנינים נסתרות וגיוון בשפות ובקטגוריות.
5. הכתבות מועלות ל-GitHub, הרשומות נשמרות ב-Supabase, וקובץ `projects.json` מתעדכן כדי להציג אותן במדור.

## הגדרת Secrets ב-Supabase

ב-Supabase Dashboard: Project Settings → Edge Functions → Secrets (או Secrets של Edge Functions), יש להוסיף:

- `OPENAI_API_KEY` — מפתח API של OpenAI. נדרש חיוב API פעיל.
- `GITHUB_TOKEN` — Fine-grained personal access token עם הרשאת Contents: Read and write למאגר `meirkremer/Hasechel-hapoel-`.

אופציונלי:
- `OPENAI_MODEL` — שם מודל API נתמך; ברירת המחדל בקוד היא `gpt-4.1`.
- `SITE_BASE_URL` — כתובת האתר הציבורית. ברירת המחדל היא `https://meirkremer.github.io/Hasechel-hapoel-`. אם האתר מחובר לדומיין מותאם אישית, יש להגדיר כאן את כתובת הדומיין המלאה.

אין להכניס מפתחות API לקובצי האתר, ל-GitHub או לטבלאות ציבוריות.

## מגבלות ובקרות איכות

- כרגע מתבצע איסוף אוטומטי מ-GitHub ומ-Hacker News; מקורות נוספים יופעלו רק לאחר מימוש adapter ובדיקתו.
- המחקר האוטומטי נשען על קובצי המאגר ונתוני GitHub שנשלפו. הוא אינו מריץ את הפרויקט ואינו מבצע audit אבטחה מלא.
- פרויקט ללא רישיון מזוהה או עם רישיון שאינו ברשימת האישור לא יפורסם.
- אם אין שלושה מועמדים שעוברים את סף האיכות, המערכת מפרסמת פחות משלושה ולא מורידה את הרף.
- קישורי ChatGPT בכל כתבה פותחים שיחה עם קישור לכתבה ובקשה לעזור להבין אותה.
